## 实验设计

采用现有 FineWeb 数据构建三个等规模训练集：semantic、random，以及两者各占 50% 的 mixed。三组共享 semantic 和 random 两套 dev/test，分别报告结果。原始来源划分保持固定，训练与评估来源隔离。

AE 输入 X、LM 输入 X 与目标 Y 均限制为 32–2048 tokens；通过筛选保留原文，样本不再截断。按 X 长度使用 32–64、65–128、129–256、257–512、513–1024、1025–2048 六档，每档 AE/LM 等量。实际配额由全部来源的可用数量共同确定。

## 训练设置

基座为 Llama-2-7B-Chat，写入与读取窗口均为 4096。压缩率 2、4、8 等概率，memory 上限 4096。所有入选样本预先验证实际写入、读取与完整上下文评估长度。

长度课程在前 30% 优化器步数内线性过渡：六档初始概率 25%、25%、20%、15%、10%、5%，最终各 1/6。dev/test 使用固定面板。三组保持相同训练步数、优化器参数及模型种子。

每个长度档内按样本随机轮转，使等量任务和混合来源在完整轮转中保持配额比例。

训练使用 BF16、梯度检查点与梯度裁剪，按长度组织 microbatch。学习率采用 warmup 后余弦衰减，每组计划 10,000 步，microbatch 为 1，梯度累积 8 次，每步抽取 8 条，总计 80,000 次样本使用。学习率峰值 3e-5，前 300 步 warmup，此后余弦衰减至 3e-6；长度课程过渡为 3,000 步。每 1,000 步保存 checkpoint 并评估，每套 dev 面板 120 条，每 2,000 步对其中 12 条执行生成评估，初始化也记录固定基线。样本使用次数与数据集遍历轮数分别记录。

## 数据与运行组织

通用准备入口由配置提供来源目录、来源比例和长度约束，输出各 run 的实际样本及选择记录；沿用 JSONL 数据格式，训练器使用数据路径，来源选择由数据准备完成。共享评估集以名称到目录的映射传给训练和独立评估入口。

SwanLab project 为 `latent-working-memory`，三组使用共同 group，训练职责为 `train`。自动标签包括 `scope:main`、`method:latent-working-memory`、`data:fineweb`，实验标签为 `study:boundary-comparison`。数据配比及课程参数保存在 config。
